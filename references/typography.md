# 中文技术文档排版细则

这些是默认写法。用户要求、项目现有规范和技术语法优先。只调整自然语言，不改代码、命令、路径、URL、配置键或 API 标识符内部的字符。

## 中文、英文和数字

- 中文与英文或阿拉伯数字之间通常留一个半角空格：`在 Linux 上运行 3 个服务`。中文标点紧邻前文：`支持 macOS、Linux 和 Windows。`
- 保留官方名称的大小写，例如 `GitHub`、`JavaScript`、`macOS`。首次出现的缩写只在读者确实需要时解释。
- 数值与单位按项目惯例和技术领域写法处理，例如 `16 GB`、`5 ms`、`20%`。范围要让上下界清楚：`5～10 ms`，必要时两端都写单位。不要把负数范围写成容易误读的连字符形式。
- 区分变化量和结果：从 100 降低了 20%，结果是 80；降低到 20%，结果是 20。涉及性能或容量时附上比较基准。

## 标点和结构

- 中文正文通常使用 `，。；：？（）“”`；英文整句、代码和技术标识符沿用其原有标点。时间、端口和协议语法保留半角冒号，例如 `08:30`、`127.0.0.1:8766`。
- 并列短项用顿号；复杂分句或列表可用分号、句号。不要为了避免某个符号把清楚的句子写得别扭。
- 省略号写成 `……`；破折号写成 `——`，只在确有停顿或解释作用时使用。不要用符号代替本应写清的条件或因果关系。
- 保持标题、列表、表格与文档原有风格一致。自动排版后检查 Markdown 链接、代码围栏、内联代码及表格列是否完整。
